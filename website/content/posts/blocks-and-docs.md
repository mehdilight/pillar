date: 2026-09-10T23:40
summary: Blocks can be selected, added, reordered and edited in the page tree; the starter's footer is built from link lists; and Pillar documents itself.
tags: [editor, docs]
---
Blocks were listed but not editable; now they are selected in the page tree, edited in the settings panel, and added only where their types are allowed — including block files a section accepts with `@theme`. The starter's footer became columns of link lists. Theme settings with a `css_var` update the preview as you drag. And this site went up: a Pillar site in the repository's `website/` folder, built on the starter as an addon.
