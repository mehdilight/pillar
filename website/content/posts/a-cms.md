---
title: A CMS beside the visual editor
date: 2026-09-10T11:27
summary: The dashboard split into a CMS for content and a visual editor for design — with a rich text editor, a media library, alt text and navigation menus.
tags: [dashboard]
---
Entries, content types, media, navigation, settings and publishing moved into a CMS with its own shell, and the visual editor became a full-screen tool of its own. Entries are written in a visual editor that reads and writes markdown and keeps diffs small. The media library gained alt text — written once, used wherever the image has none of its own — and the dashboard gained editor-managed navigation menus.
